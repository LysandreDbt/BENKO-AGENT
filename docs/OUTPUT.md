# Output contract

Analysis contains BENKO identity, dry-run mode, explicit sample flag, WATCH/REJECT, original observation time, buyRatio, reasons and fixed false executable/submitted flags.

Preview contains the analysis plus requested SOL and configured slippage, but transaction and signature are null. It is not a swap quote or a prepared transaction; no token-output estimate is invented.

Local records are unique JSON files. They record decisions, not fills. Fixture snapshots and any future real receipts must never be combined into invented performance statistics.
